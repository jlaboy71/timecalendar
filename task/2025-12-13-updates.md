## Technical Details

### Business Days Calculation Logic
```python
def count_business_days(start_date, end_date):
    if start_date > end_date:
        return 0
    business_days = 0
    current = start_date
    while current <= end_date:
        if current.weekday() < 5:  # Monday (0) to Friday (4)
            business_days += 1
        current += timedelta(days=1)
    return business_days
```

### Weekend Endpoint Check
```python
# Only check START and END dates, not dates in between
weekend_endpoints = []
if start_date.weekday() >= 5:  # 5=Saturday, 6=Sunday
    weekend_endpoints.append(('Start date', start_date.strftime('%A, %b %d')))
if end_date.weekday() >= 5:
    weekend_endpoints.append(('End date', end_date.strftime('%A, %b %d')))
```
