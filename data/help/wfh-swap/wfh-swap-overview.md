# WFH Day Swap Overview

The WFH Day Swap feature allows employees to exchange their designated Work From Home days with teammates. This is a **peer-to-peer system** - no manager approval is required.

## How It Works

1. **Each employee has a designated WFH day** (Monday through Friday)
2. **You can request to swap** with any teammate who has a different WFH day
3. **Your teammate can accept or decline** the request directly
4. **Once accepted**, both employees swap their WFH days for that week

## Key Rules

### Weekly Limit
- **One swap per week per person** - Whether you're the requester or the respondee, you can only participate in one swap per week (Monday-Sunday)
- Once you have a pending or accepted swap for a week, you cannot request or be requested for another swap that week

### Time Window
- Swap requests can only be made for dates within the **current week or next week**
- The swap date must be a **weekday** (Monday-Friday)
- The swap date must be **in the future**

### Matching Requirements
- The swap date must be the **target teammate's WFH day**
- Both you and your teammate must have designated WFH days set up
- A **message is required** when requesting and when responding

## Request Lifecycle

| Status | Description |
|--------|-------------|
| **Pending** | Request sent, awaiting teammate's response |
| **Accepted** | Teammate accepted - swap is confirmed |
| **Declined** | Teammate declined the request |
| **Cancelled** | You cancelled your pending request |
| **Expired** | No response within 3 business days |

## Tips for Success

- **Check availability first** - Look for the swap icon next to teammates' names to see who already has a swap this week
- **Include a clear reason** - Help your teammate understand why you need to swap
- **Respond promptly** - Requests expire after 3 business days
- **Plan ahead** - Request swaps early in the week for the best options
