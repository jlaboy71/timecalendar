# Manager Settings & Notification Preferences

Managers can customize their notification preferences and settings through the Settings page.

## Accessing Settings

From the Manager Dashboard:
1. Look for the **"Settings"** button (gear icon)
2. Click to open the Settings page
3. Or navigate directly to **/manager/settings**

## Notification Preferences

### Email Notifications

Control when you receive email notifications:

**Auto-Approve Notifications**
- Get notified when trusted employees' PTO is auto-approved
- Options: Immediate, Daily Digest, or Disabled

**New Request Notifications**
- Get notified when team members submit PTO requests
- Options: Immediate, Daily Digest, or Disabled

**Approval Reminders**
- Get reminded about pending approvals
- Configure reminder frequency

### Notification Frequency Options

| Option | Description |
|--------|-------------|
| **Immediate** | Email sent right away for each event |
| **Daily Digest** | Single email summarizing all events from the day |
| **Weekly Digest** | Weekly summary of all events |
| **Disabled** | No email notifications |

## Coverage Alerts

Configure alerts for potential coverage issues:

**Minimum Coverage Threshold**
- Set the minimum number of team members required
- Get alerted when approving would go below threshold

**Overlap Warnings**
- Get warnings when multiple team members request same dates
- Helps with coverage planning

## Saving Settings

- Click **"Save Changes"** to apply your preferences
- Settings take effect immediately
- Confirmation message appears on success

## Best Practices

- Start with "Immediate" notifications, adjust if volume is too high
- Use "Daily Digest" if you prefer reviewing at specific times
- Keep coverage alerts enabled for important periods
- Review settings periodically as team size changes

## Troubleshooting

**Not receiving notifications?**
- Check your email spam folder
- Verify your email address is correct
- Ensure email is configured in system settings
- Contact admin if issues persist
