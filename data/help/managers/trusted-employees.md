# Trusted Employees & Auto-Approve

Managers and administrators can designate employees as "trusted" to enable automatic PTO approval for certain leave types.

## What is a Trusted Employee?

A trusted employee is someone whose PTO requests for specific leave types are automatically approved without requiring manager review.

**Auto-approved leave types for trusted employees:**
- Vacation
- Sick
- Personal

**Not auto-approved:**
- Work From Home (WFH) - always requires manager approval

## How Auto-Approve Works

When a trusted employee submits a PTO request:

1. **Request Submitted** - Employee submits request as normal
2. **System Checks** - System detects trusted status
3. **Auto-Approved** - Request is immediately approved
4. **Manager Notified** - Manager receives an email notification about the auto-approval
5. **Reports Generated** - Auto-approval is logged in Auto Notify Reports

## Manager Notifications

When a trusted employee's PTO is auto-approved:
- Manager receives an email notification
- Email includes employee name, dates, and leave type
- A report is generated in the Auto Notify Reports section
- Managers can review all auto-approvals at any time

## Enabling Trusted Status

**For Administrators:**
1. Go to **Admin** > **Manage Employees**
2. Select the employee to edit
3. Find the **"Trusted Employee"** checkbox
4. Check the box and save changes

**Note:** Only employees with the "employee" role can be marked as trusted. Managers and admins already have auto-approve for their own requests.

## Managing Notification Preferences

Managers can control how they receive auto-approve notifications:
1. Go to **Settings** from the manager dashboard
2. Configure email notification preferences
3. Choose notification frequency (immediate, daily digest, etc.)

## Auto Notify Reports

View all auto-approved requests in the **Auto Notify Reports** section:
- Filter by department, year, month
- See weekly and monthly summaries
- Export reports for records
- Access from the Resources section on your dashboard

## Best Practices

- Grant trusted status to reliable employees with good attendance records
- Regularly review auto-approved requests via reports
- Use notification preferences to manage email volume
- Revoke trusted status if attendance issues arise
