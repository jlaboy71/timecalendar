# Auto Notify Reports

The Auto Notify Reports page provides a centralized view of all automatically approved PTO requests from trusted employees.

## Accessing Auto Notify Reports

Navigate to **Auto Notify Reports** from:
- Dashboard > Resources section (gold "Auto Notify" button)
- Or directly via the menu

## Who Can Access

- **Managers** - See reports for their department only
- **Admins/Superadmins** - Can view all departments

## Report Types

### Weekly Reports
- Generated each week
- Shows all auto-approved requests for that week
- Includes employee names, dates, leave types, and hours

### Bi-Weekly Reports
- Generated every two weeks
- Consolidated view of auto-approvals
- Useful for payroll periods

### Monthly Reports
- End-of-month summary
- Complete overview of all auto-approvals
- Great for monthly reviews

## Using Filters

### Department Filter (Superadmins only)
- Select specific department
- Or view across all departments

### Year Filter
- Select the year to view
- Shows reports from that calendar year

### Month Filter
- **Recent** - Shows current and previous month (default)
- Or select a specific month

### Type Filter
- All Types - Show all reports
- Weekly - Only weekly reports
- Bi-Weekly - Only bi-weekly reports
- Monthly - Only monthly reports

## Report Actions

### View Report
- Click any report card to open
- See full details of auto-approved requests
- Opens in a popup dialog

### Download Report
- Click the download button on any report
- Saves as HTML file
- Can be printed or archived

### Email Report
- Send report via email
- Useful for sharing with stakeholders
- Requires email configuration

## Report Contents

Each report includes:
- Report date range
- Department name
- List of auto-approved requests:
  - Employee name
  - Leave type (Vacation, Sick, Personal)
  - Date range
  - Total hours
  - Auto-approval timestamp

## How Reports Are Generated

Reports are automatically created when:
1. A trusted employee submits a PTO request
2. The system auto-approves the request
3. A notification email is sent to the manager
4. The report is stored for later review

## Best Practices

- Review reports weekly to stay informed
- Use filters to focus on specific periods
- Download monthly reports for compliance records
- Check the "Recent" view daily during busy periods
